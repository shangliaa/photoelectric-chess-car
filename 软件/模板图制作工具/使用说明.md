# 棋子模板图制作工具

把手机拍的棋子照片批量转换成 K230 `vision_ocr.py` 能用的 `.pgm` 模板图。

## 文件结构

```
模板图制作工具/
├── make_templates.py      # 主脚本
├── photos/                # 放手机拍的棋子照片（按命名规范）
└── output/                # 生成的 .pgm 模板（上传到 K230）
```

## 使用步骤

### 1. 拍照片
用手机正对每个棋子拍一张清晰照片，要求：
- 光线均匀，无反光
- 汉字居中、清晰
- 背景尽量干净（或后期裁掉）

### 2. 命名并放入 photos/
把照片重命名为对应的棋子类型，放入 `photos/` 文件夹：

| 照片文件名 | 对应棋子 | 分值 |
|-----------|---------|------|
| `red_shuai.jpg` | 红帅 | 10 |
| `red_che.jpg` | 红车 | 9 |
| `red_ma.jpg` | 红马 | 8 |
| `red_pao.jpg` | 红炮 | 7 |
| `red_xiang.jpg` | 红相 | 6 |
| `red_shi.jpg` | 红仕 | 5 |
| `red_bing.jpg` | 红兵 | 1 |
| `black_jiang.jpg` | 黑将 | 10 |
| `black_che.jpg` | 黑车 | 9 |
| `black_ma.jpg` | 黑马 | 8 |
| `black_pao.jpg` | 黑炮 | 7 |
| `black_xiang.jpg` | 黑象 | 6 |
| `black_shi.jpg` | 黑士 | 5 |
| `black_zu.jpg` | 黑卒 | 1 |

支持格式：`.jpg` `.jpeg` `.png` `.bmp` `.webp`

### 3. 运行脚本
```bash
cd 模板图制作工具
python make_templates.py
```

生成的 `.pgm` 文件在 `output/` 文件夹。

### 4. 上传到 K230
把 `output/` 里所有 `.pgm` 文件上传到 K230 的 `/sdcard/templates/` 目录。

重启 K230 后，串口应看到：
```
[OCR] 加载模板: red_shuai
[OCR] 加载模板: red_che
...
[OCR] 共加载 14 个模板
```

## 调参

如果生成的模板识别效果不好，可在 `make_templates.py` 顶部调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TEMPLATE_SIZE` | 48 | 模板尺寸（像素），越大越精细但越慢 |
| `CENTER_CROP_RATIO` | 0.6 | 从中心裁出的比例（去掉棋子外圈） |
| `BINARY_THRESHOLD` | 128 | 二值化阈值，汉字深→黑，底色浅→白 |

**调参建议**：
- 汉字偏淡看不清 → 降低 `BINARY_THRESHOLD`（如 100）
- 汉字糊成一团 → 提高 `BINARY_THRESHOLD`（如 150）
- 模板包含棋子外圈 → 降低 `CENTER_CROP_RATIO`（如 0.5）

## 验证模板效果

上传模板后，运行 `main.py`，在 `SEARCH_PIECE` 状态下观察串口输出：
```
FOUND_PIECE type=red_shuai val=10    ← 识别成功
FOUND_PIECE(unknown)                 ← 识别失败，检查模板质量
```
