# 光电象棋智能车（无舵机版）— 代码使用说明

> 版本说明：本版为**无舵机基础版**——摄像头固定朝前，扫描靠小车原地旋转。
> 升级路径：加装 2× SG90M 舵机接到预留口、K230 端换用「有舵机云台版」代码即可升级为云台版，ESP32 端代码与接线**零改动**。详见《接线说明.md》预留接线口章节。

## 一、系统架构

```
K230 (MaixPy 视觉决策)                    ESP32-S3 (MicroPython 运动执行)
┌─────────────────────┐                  ┌──────────────────────────┐
│ 摄像头采图           │   UART 115200    │ 串口指令解析              │
│ LAB 颜色识别         │ ───────────────► │ I2C→四路电机驱动(0x26)    │
│ 红/黑棋子 + 球门      │                  │ I2C→9轴IMU航向(0x23)     │
│ 目标选择 + 视觉伺服   │ ◄─────────────── │ UART2→TinyF激光测距       │
│ (原地旋转扫描)        │   状态回传        │ 航迹推算(编码器+IMU)       │
└─────────────────────┘                  └──────────────────────────┘
```

**闭环逻辑**：K230 找到己方棋子 → 让 ESP32 转向对准 → 前进推棋 → K230 持续跟踪棋子居中修正 → 棋子进入球门区 → 停止倒车 → 循环。

**核心硬件**：

| 模块 | 型号 | 接口 |
|------|------|------|
| 视觉主控 | 亚博智能 K230 一体化核心板 | — |
| 运动主控 | ESP32-S3 开发板 | — |
| 姿态传感器 | 亚博 9 轴无气压计高精度 IMU（YB-MRA02） | I2C，地址 0x23，板载姿态融合 |
| 激光测距 | TinyF 激光测距模块 ×1（车头中央） | UART 115200，ASCII 帧 |
| 电机驱动 | 四路智能电机驱动模块（AT8236×4+MCU） | I2C，地址 0x26，内置 PID+编码器 |
| 电机 | TT 编码器电机（1:45，13 线磁环）×4 | 接驱动板 M1~M4 |

## 三、引脚分配

### ESP32-S3
| 功能 | GPIO | 连接对象 |
|------|------|---------|
| I2C0 SCL | 10 | 9 轴 IMU SCL + 电机驱动 SCL |
| I2C0 SDA | 11 | 9 轴 IMU SDA + 电机驱动 SDA |
| UART1 TX | 12 | → K230 RX |
| UART1 RX | 13 | ← K230 TX |
| UART2 TX | 17 | → TinyF RX（引脚2） |
| UART2 RX | 18 | ← TinyF TX（引脚3） |
| 扩展预留 | 21、38 | 空（原 XSHUT 释放，可作扩展 IO） |

> I2C 总线频率 **100kHz**（IMU 协议要求，勿改）。上电 I2C 扫描应看到 **0x23（IMU）与 0x26（电机驱动）**。

### K230
| 功能 | 引脚 | 说明 |
|------|------|------|
| UART1 通讯口 | 4pin PH2.0（GPIO9 TX / GPIO10 RX） | ↔ ESP32 UART1 |
| 云台舵机预留口 | 12pin 排针 GPIO42(PWM0)/GPIO43(PWM1) + 5V + GND | 本版空闲，为升级预留 |
| 扩展预留 | 12pin 排针 GPIO32/33(UART3)、GPIO34/35(IIC1) | 本版空闲 |

> 完整接线表见《接线说明.md》。

## 四、通信协议

K230 ↔ ESP32 文本行协议，`\n` 结尾，波特率 115200。

### K230 → ESP32
| 指令 | 格式 | 说明 |
|------|------|------|
| MOVE | `MOVE,<距离mm>,<速度%>` | 前进（负=后退） |
| TURN | `TURN,<角度°>,<速度%>` | 原地转向（正=右转） |
| STOP | `STOP` | 立即停止 |
| POSE | `POSE` | 请求位姿 |

### ESP32 → K230
| 指令 | 格式 | 说明 |
|------|------|------|
| POSE | `POSE,<x>,<y>,<heading>` | 位姿回传 |
| DONE | `DONE,<cmd>` | 指令完成 |
| OBSTACLE | `OBSTACLE,<dist>` | 障碍物告警 |

### 传感器数据链（ESP32 内部）
- **9 轴 IMU（I2C 0x23）**：读寄存器 0x2E 得 YAW（float 小端，弧度）→ 转为度，供航向闭环与航迹推算。板载 9 轴融合，**无需开机静止校准**。
- **TinyF（UART2）**：模块以约 30Hz 主动输出 ASCII 帧 `"距离, 状态\n"`（如 `" 327, 0\n"` = 327mm，状态 0 有效）；状态非 0、超 4000mm 或 100ms 无新帧视为无效（-1，不触发避障）。
- **四路电机驱动（I2C 0x26）**：寄存器 0x06 写 4×int16 速度（-1000~1000，大端）；编码器总脉冲读 0x20-0x27（仅用前轮 M1/M3）。

## 五、ESP32-S3 烧录步骤

### 1. 烧录 MicroPython 固件
- 固件位置：`硬件/硬件说明书/ESP32-S3/0-Firmware/uf2/micropython.uf2` 或 `bin/micropython.bin`
- 烧录工具：`硬件/硬件说明书/ESP32-S3/烧录调试工具/固件烧录工具/flash_download_tool/`
- 步骤：
  1. ESP32-S3 进入下载模式（按住 BOOT，按一下 RESET，松开 BOOT）
  2. 打开 flash_download_tool，选择 ESP32-S3
  3. 加载 `micropython.bin`，地址填 `0x0`
  4. 选择正确 COM 口，点击 START
  5. 完成后按 RESET 复位

### 2. 上传代码
- 工具：Thonny / uPyCraft / Ampy
- 将 `ESP32-S3端代码/` 下所有 `.py` 文件上传到 ESP32 文件系统根目录
- `main.py` 上电自动运行

### 3. 单元测试（可选但强烈建议）
每个模块末尾有 `if __name__ == '__main__'` 测试代码，可单独上传运行验证：
- `motor.py`：看车轮正反转，观察编码器脉冲数（前进时左前/右前脉冲应增加）
- `imu.py`：旋转小车看航向；**右转（顺时针）时航向应增大**，若减小，把 `config.py` 中 `IMU_YAW_SIGN` 改为 `-1.0`
- `tinyf.py`：用手遮挡车头看距离变化；无输出则检查 TX/RX 是否接反

## 七、颜色阈值校准（关键！）

K230 端 `config.py` 中的颜色阈值**必须在赛场光线下现场校准**，否则识别不稳定。

### 校准方法
1. 将一枚红方棋子放在赛场，用 CanMV IDE 的阈值编辑器（LAB 滑块）调整，直到色块框稳定框住棋子
2. 记录 `(Lmin, Lmax, Amin, Amax, Bmin, Bmax)`，填入 `RED_THRESHOLD`
3. 同样方法校准 `BLACK_THRESHOLD`（黑方棋子）
4. 校准 `GOAL_THRESHOLD`（球门区颜色）—— 球门颜色由赛场决定，若球门无法用颜色区分，可改用「朝固定方向推棋」策略

### 己方颜色设置
- 默认红方：`MY_COLOR = 'red'`
- 若为黑方：改为 `MY_COLOR = 'black'`

## 八、整机联调测试

1. **接线检查**：按《接线说明.md》接线，确认 5V/3.3V/GND 无误，全系统共地
2. **单独上电 ESP32**：串口应打印 `I2C 设备: ['0x23', '0x26']` 和 `IMU 就绪（9轴算法...）`、`READY`
3. **单元测试**：依次跑 `motor.py`、`imu.py`、`tinyf.py` 的测试代码（见第五节）
4. **PC 串口助手测试 ESP32**：发 `MOVE,100,50` 看小车前进并回 `DONE,MOVE`；发 `TURN,90,40` 看原地右转
5. **K230 单独测试视觉**：运行 `vision.py`，LCD 上看色块框选
6. **K230 + ESP32 联调**：两串口互连，放一枚己方棋子在车前，观察自动对准推进
7. **扫描测试（本版重点）**：确保视野内无球门时小车以 45° 步进原地旋转扫描，找到球门后停止旋转并居中
8. **赛场测试**：放多枚棋子，验证连续推棋循环

## 九、常见问题

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| I2C 扫描为空 / 缺 0x23 或 0x26 | SCL/SDA 接反、模块未供电、无上拉 | 检查 GPIO10/11 接线与模块供电；确认 IMU/驱动板 VCC |
| IMU 打印「算法类型非9」 | 曾用上位机改过配置 | 用 IMU 上位机切回 9 轴算法 |
| 右转时航向减小 | IMU 安装朝向与默认相反 | `config.py` 中 `IMU_YAW_SIGN` 改为 `-1.0` |
| TinyF 一直输出 -1 | TX/RX 接反 / 波特率不符 / 供电不足 | 确认 GPIO17→TinyF RX、GPIO18←TinyF TX，VDD 接 5V；若帧格式与预期不符，用 USB-TTL 串口助手（115200）抓帧比对，改 `tinyf.py` 的 `_parse()` |
| 电机不转 | I2C 接线错 / 驱动未供电 | 检查驱动板 SDA/SCL 与 VM 接电池 7.4V；跑 `motor.py` 单元测试 |
| 编码器脉冲不增加 | 编码器线未接驱动板 / 读取寄存器异常 | 确认电机编码器 PH2.0-6P 线接驱动板；`motor.py` 测试观察 M1/M3 脉冲 |
| K230 识别不到棋子 | 颜色阈值不准 / 光线 | 重新校准 LAB 阈值 |
| 小车推棋跑偏 | 航向符号反 / 修正系数不当 | 先标定 `IMU_YAW_SIGN`；再按实测调整 `motion.py` 中 `corr * 2.0` |
| 找不到球门时小车不动 | ESP32 未回 DONE / 串口未连 | 检查串口联调；看 K230 串行终端 `ESP32:` 回传 |
| 球门识别失败 | 球门颜色未知 | 校准 `GOAL_THRESHOLD`，或改用固定方向策略 |

## 十、与有舵机云台版的差异

| 项目 | 无舵机版（本版） | 有舵机云台版 |
|------|----------------|-------------|
| 扫描方式 | 小车原地 45° 步进旋转 | 云台先扫，必要时小车配合旋转 |
| K230 端文件 | 5 个（无 servo.py） | 6 个（含 servo.py） |
| ESP32 端代码 | **完全相同** | **完全相同** |
| 硬件需求 | 无舵机 | 2× SG90M 接预留口（GPIO42/43+5V+GND） |

升级方法见《接线说明.md》末尾「升级路径」章节。
