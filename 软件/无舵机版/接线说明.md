# 光电象棋智能车（无舵机版）— 接线说明

> 接线前请断电操作；所有模块**必须共地**（GND 连通）。
> 本版预留了云台舵机升级接线口，升级方法见文末「升级路径」。

## 一、系统电源树

```
2S 7.4V 锂电池 ──► 电源总开关 ──┬──► 四路电机驱动板 VM（直供电机，7.4V）
                              │     （1000μF 滤波电容×2 就近并联在 VM 输入端）
                              └──► DC-DC 降压模块（5V/2A）
                                    ├──► ESP32-S3（5V/VIN）
                                    ├──► K230（供电口/5V）
                                    ├──► 9轴IMU VCC（模块 3.3~5V 宽压，板载 LDO）
                                    └──► TinyF VDD（必须 5V）
```

- 电池、开关、DC-DC 正负极切勿接反；DC-DC 输出先空载测得 5.0V 再接模块。
- 全车 GND：电池负极、驱动板 GND、ESP32 GND、K230 GND、IMU GND、TinyF GND 全部连通。

## 二、ESP32-S3 接线总表

| ESP32 引脚 | 方向 | 连接对象 | 对方引脚 | 说明 |
|-----------|------|---------|---------|------|
| GPIO10 (I2C0 SCL) | ↔ | 9 轴 IMU + 电机驱动板 | SCL | I2C 时钟，100kHz |
| GPIO11 (I2C0 SDA) | ↔ | 9 轴 IMU + 电机驱动板 | SDA | I2C 数据 |
| GPIO12 (UART1 TX) | → | K230 通讯口 | RX（引脚4） | 与 K230 互连 |
| GPIO13 (UART1 RX) | ← | K230 通讯口 | TX（引脚3） | 与 K230 互连 |
| GPIO17 (UART2 TX) | → | TinyF | RX（引脚2） | 测距串口 115200 |
| GPIO18 (UART2 RX) | ← | TinyF | TX（引脚3） | 测距串口 115200 |
| 5V/VIN | ← | DC-DC 5V | 输出 | 供电 |
| GND | ↔ | 公共地 | — | 共地 |

> I2C 为共享总线：IMU 与电机驱动板的 SCL 并联接 GPIO10，SDA 并联接 GPIO11（地址 0x23 与 0x26 不冲突）。模块一般自带上拉电阻；若 I2C 扫描不到设备，在 SCL/SDA 上各加 4.7kΩ 上拉至 3.3V。

## 三、K230 接线

| K230 引脚 | 方向 | 连接对象 | 对方引脚 | 说明 |
|-----------|------|---------|---------|------|
| 通讯口 5V（4pin-1） | — | 不接 | — | K230 由自身供电口供电 |
| 通讯口 GND（4pin-2） | ↔ | ESP32 GND | — | 与 ESP32 共地（必接） |
| 通讯口 UART1_TXD（4pin-3，GPIO9） | → | ESP32 | GPIO13（RX） | 交叉接线 |
| 通讯口 UART1_RXD（4pin-4，GPIO10） | ← | ESP32 | GPIO12（TX） | 交叉接线 |

> K230 的 12pin 排针（散热片旁）本版**全部空闲**，其中 GPIO42/43+5V+GND 为云台升级预留口，详见第六节。

## 四、9 轴 IMU（YB-MRA02）接线

| IMU 引脚 | 连接 | 说明 |
|---------|------|------|
| VCC/5V | DC-DC 5V（或 ESP32 3.3V） | 模块 3.3~5V 宽压，板载 LDO |
| GND | 公共地 | — |
| SCL | ESP32 GPIO10 | 与电机驱动板 SCL 并联 |
| SDA | ESP32 GPIO11 | 与电机驱动板 SDA 并联 |
| RX / TX | **悬空** | UART 方式本车不用（走 I2C） |

**安装方向（重要）**：车体几何中心，**Z 轴朝上、X 轴指向车头**。若右转时航向减小，在 `ESP32-S3端代码/config.py` 中将 `IMU_YAW_SIGN` 改为 `-1.0`（无需重新接线）。

## 五、TinyF 激光测距 + 四路电机驱动板

### TinyF（车头中央，发射窗朝前）
| TinyF 引脚 | 连接 | 说明 |
|-----------|------|------|
| 1 VDD | DC-DC 5V | 必须 5V |
| 2 RX | ESP32 GPIO17（TX） | 交叉 |
| 3 TX | ESP32 GPIO18（RX） | 交叉 |
| 4 GND | 公共地 | — |
| 5、6 | 悬空 | 官方注明用户无需使用 |

### 四路电机驱动板
| 驱动板 | 连接 | 说明 |
|--------|------|------|
| VM | 电池正极（经开关，7.4V） | 电机主电源，1000μF×2 就近并联 |
| GND | 公共地 | 与电池负极、逻辑地连通 |
| SDA / SCL | ESP32 GPIO11 / GPIO10 | I2C 地址 0x26 |
| M1 | 左前 TT 电机 | 编码器线接驱动板对应编码器口 |
| M2 | 左后 TT 电机 | 同上 |
| M3 | 右前 TT 电机 | 同上 |
| M4 | 右后 TT 电机 | 同上 |
| 编码器接口 ×4 | 各电机霍尔编码器（PH2.0-6P） | 供电由驱动板提供 |

> 电机转向若与预期相反（前进变后退），优先交换对应电机两根动力线；或在 `motor.py` 中把 `DualMotor` 的 `_left_sign/_right_sign` 改为 -1。

## 六、预留接线口（升级与扩展）

> 本版为无舵机基础版，以下接口已**物理预留**，升级/扩展时直接使用，无需改线。

### 1. 云台舵机升级预留口（K230 12pin 排针）
| 预留信号 | 12pin 位置 | 用途 |
|---------|-----------|------|
| GPIO42（PWM0） | 排针 1 | 水平舵机信号线（橙/黄） |
| GPIO43（PWM1） | 排针 2 | 俯仰舵机信号线（橙/黄） |
| GND | 排针 4、7 | 舵机棕线 |
| 5V 输出 | 排针 9、11 | 舵机红线 |
| 3.3V 输出 | 排针 12 | 备用 |

### 2. K230 扩展预留
| 预留信号 | 12pin 位置 | 用途 |
|---------|-----------|------|
| GPIO32（UART3_TXD）/ GPIO33（UART3_RXD） | 排针 5、3 | 备用串口（可接第二测距等） |
| GPIO34 / GPIO35（IIC1 SCL/SDA） | 排针 8、10 | 备用 I2C |

### 3. ESP32 扩展预留
| 预留 GPIO | 说明 |
|-----------|------|
| GPIO21、GPIO38 | 原测距模块 XSHUT 引脚释放，可接扩展传感器/备用 IO |

## 七、升级路径：无舵机版 → 有舵机云台版

1. **硬件**：将 2× SG90M 舵机装上二自由度云台支架（车前部），信号线接上表「云台舵机升级预留口」——水平舵机→GPIO42、俯仰舵机→GPIO43、红→5V、棕→GND（**注意：舵机堵转电流较大，2 只舵机峰值可达 1A 以上，动作时避免长时间堵转**）。
2. **软件**：K230 端代码整体替换为 `软件/有舵机云台版/K230端代码/`（多 `servo.py` 与云台扫描逻辑）；ESP32 端代码**无需任何改动**。
3. **验证**：先单独运行 K230 端 `servo.py` 的测试代码确认云台水平/俯仰动作正常，再整机联调。

升级后接线全景与舵机注意事项详见《有舵机云台版/接线说明.md》。
