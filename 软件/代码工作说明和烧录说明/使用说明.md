# 光电象棋智能车 — 代码工作说明与烧录说明

## 一、系统架构

```
K230 (MaixPy 视觉决策)                    ESP32-S3 (MicroPython 运动执行)
┌─────────────────────┐                  ┌──────────────────────┐
│ 摄像头采图           │   UART 115200    │ 串口指令解析          │
│ LAB 颜色识别         │ ───────────────► │ 电机 PID 调速         │
│ 红/黑棋子 + 球门      │                  │ 航迹推算(编码器+IMU)  │
│ 目标选择 + 视觉伺服   │ ◄─────────────── │ 舵机云台控制          │
│ 下发运动指令          │   状态回传        │ VL53L0X 避障          │
└─────────────────────┘                  └──────────────────────┘
```

**闭环逻辑**：K230 找到己方棋子 → 让 ESP32 转向对准 → 前进推棋 → K230 持续跟踪棋子居中修正 → 棋子进入球门区 → 停止倒车 → 循环。

## 三、ESP32-S3 引脚分配

| 功能 | GPIO | 模块 |
|------|------|------|
| 左电机 PWM | 4 | TB6612 PWMA |
| 左电机 IN1 | 5 | TB6612 AIN1 |
| 左电机 IN2 | 6 | TB6612 AIN2 |
| 右电机 PWM | 7 | TB6612 PWMB |
| 右电机 IN1 | 15 | TB6612 BIN1 |
| 右电机 IN2 | 16 | TB6612 BIN2 |
| TB6612 STBY | 14 | 使能（可直连 3.3V 省引脚） |
| 左编码器 A | 1 | AB 相 |
| 左编码器 B | 2 | AB 相 |
| 右编码器 A | 41 | AB 相 |
| 右编码器 B | 42 | AB 相 |
| 云台水平舵机 | 8 | PWM 50Hz |
| 云台俯仰舵机 | 9 | PWM 50Hz |
| I2C SCL | 10 | MPU6050 + VL53L0X |
| I2C SDA | 11 | |
| VL53L0X 左 XSHUT | 21 | 地址重置 |
| VL53L0X 右 XSHUT | 38 | 地址重置 |
| UART1 TX | 12 | → K230 RX |
| UART1 RX | 13 | ← K230 TX |

> 接线改动只需修改 `ESP32-S3 Micropython代码/config.py`。

### I2C 设备地址
- MPU6050：0x68
- VL53L0X 左：0x30（开机由 XSHUT 重置后改址）
- VL53L0X 右：0x31

## 四、通信协议

文本行协议，`\n` 结尾，波特率 115200。

### K230 → ESP32
| 指令 | 格式 | 说明 |
|------|------|------|
| MOVE | `MOVE,<距离mm>,<速度%>` | 前进（负=后退） |
| TURN | `TURN,<角度°>,<速度%>` | 原地转向（正=右转） |
| STOP | `STOP` | 立即停止 |
| SERVO | `SERVO,<pan>,<tilt>` | 云台角度 0-180 |
| POSE | `POSE` | 请求位姿 |
| SCAN | `SCAN` | 云台扫描 |

### ESP32 → K230
| 指令 | 格式 | 说明 |
|------|------|------|
| POSE | `POSE,<x>,<y>,<heading>` | 位姿回传 |
| DONE | `DONE,<cmd>` | 指令完成 |
| OBSTACLE | `OBSTACLE,<dist>` | 障碍物告警 |

## 五、ESP32-S3 烧录步骤

### 1. 烧录 MicroPython 固件
- 固件位置：`硬件/硬件说明书/ESP32-S3/0-Firmware/uf2/micropython.uf2` 或 `bin/micropython.bin`
- 烧录工具：`硬件/硬件说明书/ESP32-S3/烧录调试工具/固件烧录工具/flash_download_tool/`
- 步骤：
  1. ESP32-S3 进入下载模式（按住 BOOT，按一下 RESET，松开 BOOT）
  2. 打开 flash_download_tool，选择 ESP32-S3
  3. 加载 `micropython.bin`，地址填 `0x0`
  4. 选择正确 COM 口，点击 START
  5. 完成后按 RESET 复位

### 2. 上传代码
- 工具：Thonny / uPyCraft / Ampy
- 将 `ESP32-S3 Micropython代码/` 下所有 `.py` 文件上传到 ESP32 文件系统根目录
- `main.py` 上电自动运行

### 3. 单元测试（可选）
每个模块末尾有 `if __name__ == '__main__'` 测试代码，可单独运行验证：
- `encoder.py`：转动轮子看脉冲数
- `motor.py`：看车轮正反转
- `imu.py`：旋转小车看航向角
- `vl53l0x.py`：遮挡看测距值
- `servo.py`：看云台转动

## 七、颜色阈值校准（关键！）

K230 端 `config.py` 中的颜色阈值**必须在赛场光线下现场校准**，否则识别不稳定。

### 校准方法
1. 将一枚红方棋子放在赛场，用 K230  IDE 的阈值编辑器（LAB 滑块）调整，直到色块框稳定框住棋子
2. 记录 `(Lmin, Lmax, Amin, Amax, Bmin, Bmax)`，填入 `RED_THRESHOLD`
3. 同样方法校准 `BLACK_THRESHOLD`（黑方棋子）
4. 校准 `GOAL_THRESHOLD`（球门区颜色）—— 球门颜色由赛场决定，若球门无法用颜色区分，可改用「朝固定方向推棋」策略

### 己方颜色设置
- 默认红方：`MY_COLOR = 'red'`
- 若为黑方：改为 `MY_COLOR = 'black'`

## 八、整机联调测试

1. **接线检查**：按第三节引脚表接线，确认 5V/3.3V/GND 无误
2. **单独上电 ESP32**：串口应打印 `I2C 设备: [...]`（含 0x68、0x30、0x31）和 `READY`
3. **PC 串口助手测试 ESP32**：发 `MOVE,100,50` 看小车前进并回 `DONE,MOVE`
4. **K230 单独测试视觉**：运行 `vision.py`，LCD 上看色块框选
5. **K230 + ESP32 联调**：两车串口互连，放一枚己方棋子在车前，观察自动对准推进
6. **赛场测试**：放多枚棋子，验证连续推棋循环

## 九、常见问题

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| ESP32 打印 I2C 设备为空 | 接线/地址错误 | 检查 SCL/SDA、上拉电阻 |
| VL53L0X 只有一个地址 | XSHUT 接线或改址失败 | 检查 XSHUT 引脚，确认两模块地址 0x30/0x31 |
| 电机不转 | STBY 未拉高 / PWM 引脚错 | STBY 接 3.3V 或 GPIO14 输出高 |
| 编码器脉冲不增加 | AB 相接反或引脚错 | 交换 A/B 或检查引脚 |
| K230 识别不到棋子 | 颜色阈值不准 / 光线 | 重新校准 LAB 阈值 |
| 小车推棋跑偏 | IMU 未校准 / 航向漂移 | 开机保持静止完成校准 |
| 球门识别失败 | 球门颜色未知 | 校准 GOAL_THRESHOLD，或改用固定方向策略 |
