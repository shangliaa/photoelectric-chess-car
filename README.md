# 光电象棋智能车（第十五届全国大学生光电设计竞赛 赛题一）

基于 **K230 视觉核心 + ESP32-S3 运动控制** 双芯架构的全自主光电象棋智能车。

## 项目结构

│   │   ├── K230端代码/            # 视觉决策端（色块识别、状态机、串口通信）
│   │   ├── ESP32-S3端代码/        # 运动控制端（I2C 电机驱动/IMU、UART 测距）

## 系统架构

- **K230（MaixPy）**：摄像头采集 → LAB 颜色空间识别红/黑棋子与球门 → 视觉伺服决策 → UART 下发运动指令；云台版另经 GPIO42/43 PWM 直接控制云台
- **ESP32-S3（MicroPython）**：接收指令 → I2C 控制四路智能电机驱动（内置 PID+编码器，地址 0x26）→ I2C 读取 9 轴 IMU 航向（板载姿态融合，地址 0x23）→ UART2 读取 TinyF 激光测距避障 → 状态回传

## 核心硬件

| 模块 | 型号 |
|------|------|
| 视觉主控 | 亚博智能 K230 一体化集成核心板 |
| 运动主控 | ESP32-S3 开发板 |
| 电机驱动 | 四路智能电机驱动模块（AT8236×4+MCU，I2C 0x26）×1 |
| 电机 | TT编码器电机（1:45，6V 350RPM，金属轴，霍尔AB相，13线磁环）×4 |
| 底盘 | 四驱轮式小车（228×148×102.15mm，65mm轮） |
| IMU | 9 轴无气压计高精度 IMU 姿态传感器（YB-MRA02，I2C 0x23） |
| 测距 | TinyF 激光测距模块（UART，车头中央）×1 |
| 舵机（云台版） | SG90M ×2（二自由度云台，K230 PWM 直控 GPIO42/43） |
| 电源 | 2S 7.4V 锂电池 + 5V/2A DC-DC |
