# 光电象棋智能车（第十五届全国大学生光电设计竞赛 赛题一）

基于 **K230 视觉核心 + ESP32-S3 运动控制** 双芯架构的全自主光电象棋智能车。

## 项目结构

```
.
├── 软件/
│   ├── ESP32-S3 Micropython代码/   # 运动控制端代码（四路驱动UART通信、IMU、测距）
│   ├── K230端代码/                  # 视觉决策端代码（色块识别、状态机、串口通信、云台PWM控制）
│   └── 代码工作说明和烧录说明/       # 使用说明文档
├── 硬件/
│   └── 硬件接线示意图/              # 完整硬件接线图（SVG/PNG/PDF）
└── 论文/
    └── 光电象棋智能车硬件系统设计与实现.pdf  # 硬件设计论文
```

## 系统架构

- **K230（MaixPy）**：摄像头采集 → LAB 颜色空间识别红/黑棋子与球门 → 视觉伺服决策 → UART 下发运动指令 + PWM 直接控制云台
- **ESP32-S3（MicroPython）**：接收指令 → 四路智能电机驱动（UART，内置PID+编码器） → MPU6050 航向闭环 → VL53L0X 避障 → 状态回传

## 核心硬件

| 模块 | 型号 |
|------|------|
| 视觉主控 | 亚博智能 K230 一体化核心板 |
| 运动主控 | ESP32-S3 开发板 |
| 电机驱动 | 四路智能电机驱动模块（AT8236×4+MCU，UART/I2C）×1 |
| 电机 | TT编码器电机（1:48，霍尔AB相）×4 |
| 底盘 | 四驱轮式小车（228×148×102.15mm，65mm轮） |
| IMU | MPU6050 |
| 测距 | VL53L0X ×2 |
| 舵机 | SG90M ×2（二自由度云台，K230 PWM 直控 GPIO42/43） |
| 电源 | 2S 7.4V 锂电池 + 5V/2A DC-DC |
